# 01 任务链路与状态机

## 状态机

> 规则上的一圈是五段：识别 → 取样 → **化验区空闲识别** → 提交样本 → 回起点。本文只写车侧状态机的三段；第三段（化验区窗口空闲状态）由 `OCR_CAM.py` 独立发布 `/board2_result`，**未接入任务决策**，说明见 [`05-限时与跑位.md`](05-限时与跑位.md#规则里的化验区空闲识别在实现里是什么位置)。

`F1_yaofang.py` 的调度只有三个状态，用 `self.count` 表示，初始 `9`（`:204`）：

```
count=9  ──go_to_recognize_area()──▶ 10        # 任务1：识别板1 读处方
count=10 ──go_to_dispense_area()──▶ 11         # 任务2：按处方去 C/A/B 窗口取样
count=11 ──go_to_delivery_area()──▶ 9          # 任务4：送对应化验窗口 → 回起点
```

主循环（`:232-239`）是空转轮询：

```python
while not rospy.is_shutdown():
    if self.count == 9:   self.go_to_recognize_area()
    elif self.count == 10: self.go_to_dispense_area()
    elif self.count == 11: self.go_to_delivery_area()
    rospy.sleep(0.1)
```

三个状态转换都在函数末尾赋值，中途任何一步失败（导航超时/识别失败）也不会卡在中间态——每个 `go_to_*` 内部对所有分支都收敛到「推进状态」或「用默认值推进状态」。

合法性校验（`:292-297`）要求同时满足：

```python
len(result) >= 6                              # 6 字段协议
result[3] in [1, 2, 3]                        # 样本数
result[4] in [0, 1, 2, 3]                     # 板位 → 化验窗口序号
all(v in [0, 1] for v in result[0:3])         # 三个窗口标志位只能是 0/1
```

`reversed(self.received_results)` 从最新往回找，因为越晚的结果通常对应车停得越稳、解码越可信。

## 任务2：取样（`:336-374`）

- `window_order = [('C',0),('A',1),('B',2)]`（`:340`），按 `windows_go[i]` 是否为 1 决定去不去——三个窗口最多三个，最少一个
- 每个窗口：`update_task(name)` → `clear_costmaps` → `move_to` → 停 `pause_time`（`0.25 s`）→ 日志确认
- 全部取完后拼播报文本（`:359-371`）并播语音：`<样本拼音><窗口字母组合>.mp3`，如 `jingmaixueAB.mp3`（`:474-477`）

## 任务4：送检（`:376-437`）

两条分支：

- **单窗口送检**（正常路径，`:396-418`）：`lab_window` 0/1/2/3 映射到化验区「1 号激素检验 / 2 号免疫检测 / 3 号体液 / 4 号血常规」——`lab_positions = {0:6, 1:5, 2:4, 3:3}`（`:399`），对应 `waypoints[6..3]`
- **全部化验区**（`visit_all_labs=True`，`:380-395`）：依次跑 6/5/4/3 号点，每个点播报「到达 X 窗口，样本数为 N」

送检语音：`<拼音前缀><样本数>.mp3`，如 `xuechanggui3.mp3`（`:416-417`）——按「窗口 + 份数」组合预先录好，避免现场 TTS。

最后回起点 `waypoints[7]`，停 `home_pause_time`（`1.0 s`），重置全部状态，`count=9` 等下一轮（`:420-437`）。

## 导航封装

```python
def move_to(self, goal):
    self.move_base.send_goal(goal)
    finished = self.move_base.wait_for_result(rospy.Duration(30))   # :448
    if not finished:
        self.move_base.cancel_goal()
        rospy.logwarn("导航超时")
        return False
    return self.move_base.get_state() == GoalStatus.SUCCEEDED
```

- 超时 30 s 是「一段路的硬上限」：4 分钟内要跑 5–6 段路，任何一段卡死都必须放弃而不是原地重试
- 返回 `False` 时调用方**不中断**，继续下一个点——少取一个窗口的样本仍能拿部分分，卡死则零分
- 每次发目标前都 `clear_costmaps`：车在窄道被障碍物残留的代价地图困住时，清图比重新规划更有效，代价是局部定位可能跳一次（这也是上报用标定坐标的原因，见 `02-裁判软件上报协议.md`）
